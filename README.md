# Parrondo Drift, Localization, and Directed Transport in a One-Defect Discrete-Time Quantum Walk with Coin Dephasing

**Confirmatory Atlas and Deterministic Analysis of the Noiseless Slice**

This is the cleaned, paper-facing repository for the PH4511 project. It keeps only the
material needed to inspect the archived computational work honestly and rerun the stages
that generated the included outputs.

## What is kept

- `src/dtqw/`: the reusable DTQW package used by the stage scripts.
- `src/tests/`: small validation tests for the core guardrails and metric routines.
- `scripts/`: the stage scripts that generate the archived outputs and paper-facing figures/reports.
- `outputs/`: the full archived run directories for stages 0--8, kept intact.
- `figures/stage3/` and `figures/stage8/`: the paper-facing figure copies used by the current LaTeX manuscript.
- `reports/`: stage-3 report outputs generated by `scripts/stage3_extract_insights.py`.
- `dev.yaml` and `mrc.yaml`: the working configuration files used by the development and confirmatory pipelines.

## Stage status

- **Stage 0** is the baseline replication used in the paper.
- **Stage 1** and **Stage 2** are kept for transparency. They are exploratory/developmental runs that are explicitly described in the manuscript, but they are not part of the locked confirmatory claim chain.
- **Stage 3** is the confirmatory atlas used in the current manuscript.
- **Stages 4--8** are the deterministic noiseless-slice follow-up used in the current manuscript.
