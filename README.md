# Parrondo Drift, Localization, and Directed Transport in a One-Defect Discrete-Time Quantum Walk with Coin Dephasing

**Confirmatory Atlas and Deterministic Analysis of the Noiseless Slice**

This repository contains the code and archived outputs for the PH4511 project. It is the version that goes with the final paper, so the aim here is simple: keep the computational record clear, keep the figure sources easy to trace, and keep the scripts runnable without extra clutter.

The repository includes the core `dtqw` package, the stage scripts, the fixed output directories, the figure copies used in the manuscript, and the configuration files needed to rerun the pipeline.

## What is in the repository

- `src/dtqw/` contains the reusable DTQW code.
- `src/tests/` contains small checks for the core routines.
- `scripts/` contains the stage scripts used to generate the archived outputs and the paper-facing figures.
- `outputs/` contains the archived run directories for stages 0--8.
- `figures/stage3/` and `figures/stage8/` contain the figure copies used directly in the LaTeX manuscript.
- `reports/` contains the stage-3 report material generated by `scripts/stage3_extract_insights.py`.
- `dev.yaml` and `mrc.yaml` are the configuration files used by the development and confirmatory pipelines.

## How the stages are used

Stage 0 is the baseline replication used in the paper.

Stages 1 and 2 are kept for transparency. They are exploratory runs, and the manuscript says so explicitly. They are part of the project history, but they are not part of the locked confirmatory claim chain.

Stage 3 is the confirmatory atlas used for the main finite-horizon results.

Stages 4--8 are the deterministic follow-up on the noiseless slice `p = 0`.

## Reproduction order

The fixed outputs are already included, so you do not need to rerun anything just to inspect the results. If you want to reproduce the stage pipeline from the repository root, use the commands below.

```bash
python scripts/stage0_jan_replication.py --config dev.yaml
python scripts/stage1_defect_phi_scan.py --config dev.yaml
python scripts/stage2_pd_atlas.py --config dev.yaml
python scripts/stage2_postprocess_figures.py --run_dir outputs/run_20260210_144641_stage2_pd_atlas

python scripts/stage3_confirmatory_pd_atlas_cpu.py --config mrc.yaml --jobs 8
python scripts/stage3_postprocess_figures.py --run_dir outputs/run_20260212_090815_stage3_pd_confirmatory
python scripts/stage3_extract_insights.py --run_dir outputs/run_20260212_090815_stage3_pd_confirmatory

python scripts/stage4_exact_p0_audit.py --config mrc.yaml --stage3_run_dir outputs/run_20260212_090815_stage3_pd_confirmatory
python scripts/stage5_rigour_suite_longrun.py --config mrc.yaml --repo_root . --stage4_run_dir outputs/run_20260322_094517_stage4_exact_p0_audit
python scripts/stage6_exact_p0_math_suite.py --config mrc.yaml --stage4_run_dir outputs/run_20260322_094517_stage4_exact_p0_audit --stage5_run_dir outputs/run_20260322_105844_stage5_rigour_suite_longrun
python scripts/stage7_exact_p0_asymptotic_suite.py --config mrc.yaml --stage4_run_dir outputs/run_20260322_094517_stage4_exact_p0_audit --stage5_run_dir outputs/run_20260322_105844_stage5_rigour_suite_longrun --stage6_run_dir outputs/run_20260322_125852_stage6_exact_p0_math_suite
python scripts/stage8_rigour_bridge_suite.py --config mrc.yaml --stage4_run_dir outputs/run_20260322_094517_stage4_exact_p0_audit --stage5_run_dir outputs/run_20260322_105844_stage5_rigour_suite_longrun --stage7_run_dir outputs/run_20260322_161029_stage7_exact_p0_asymptotic_suite
python scripts/stage8_postprocess_figures.py --repo_root . --stage8_run_dir outputs/run_20260322_194423_stage8_rigour_bridge_suite --stage3_run_dir outputs/run_20260212_090815_stage3_pd_confirmatory
```
